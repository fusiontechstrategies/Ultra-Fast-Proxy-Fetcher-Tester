# Responsible Use

Ultra-Fast Proxy Fetcher & Tester is provided for lawful, authorized network testing, development, and research.

## Appropriate uses

- Testing software you own against proxy transport behavior.
- Validating networking libraries in a controlled lab.
- Studying public proxy volatility without transmitting sensitive information.
- Quality assurance and defensive research performed with permission.

## Unacceptable uses

- Bypassing access controls, rate limits, bans, geographic restrictions, or service policies.
- Credential attacks, account abuse, fraud, spam, harassment, or traffic laundering.
- Unauthorized scraping, scanning, denial-of-service activity, or attempts to hide malicious traffic.
- Routing credentials, personal information, proprietary data, or other sensitive material through public proxies.
- Targeting systems or services without the owner's explicit authorization.

The software's MIT license does not make an otherwise unlawful or unauthorized activity acceptable. Operators are responsible for following applicable law, contractual obligations, source policies, and network-provider rules.

The program intentionally uses a fixed HTTPS connectivity endpoint and does not accept arbitrary test targets. Contributions that weaken these safeguards will not be accepted.
