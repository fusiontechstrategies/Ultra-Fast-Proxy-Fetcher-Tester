# Support

Use GitHub Issues for reproducible defects and focused feature requests. Include the Python version, operating system, command used, exit code, and sanitized output.

Do not post working proxy endpoints, credentials, private source URLs, personal data, or sensitive logs in an issue.

Questions about bypassing safeguards, access controls, rate limits, or third-party policies are outside the project's support scope.

Report security concerns privately as described in [SECURITY.md](SECURITY.md).
